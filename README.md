# 片刻拼图 · Piece by piece

React 18 + 严格 TypeScript + Vite + Tailwind CSS。原生 Pointer Events、Canvas、SVG、IndexedDB、Web Audio。普通单人游戏在浏览器本地处理；用户主动创建照片分享或双人房间时，使用新增的 Node HTTP 服务。内置图片和音乐不依赖远程服务。

## 个人体验版

当前Vercel配置优先发布无需后端的个人体验版，运行 `npm run build:personal`。单人、闯关、音乐、本地收藏及导出保留，云端入口在该构建中收起；本地开发完整功能不变。具体范围和验收见 [个人体验版发布记录](PERSONAL_RELEASE.md)。

## 公网部署

完整功能采用Vercel前端加独立持久化Node后端。部署配置已准备，尚未发布；需要连接云账户并确认后端费用。具体参数、发布顺序与验收见 [部署说明](DEPLOYMENT.md)。

## 运行

```powershell
cd E:\codex\拼图
npm install
npm start
```

访问 http://127.0.0.1:5173/ 。`npm start` 在后台启动前端5173与联机API5175，复用已运行的服务；关闭启动终端不会停止它，电脑重启后需重新启动。需要前台开发时，在两个终端分别执行 `npm run dev` 和 `npm run server`。

```powershell
npm test
npm run build
npm run preview
```

`dist/` 可静态部署单人游戏；照片链接与实时联机还需运行Node服务。当前仅在本机运行，127.0.0.1链接不能让远程朋友访问。部署与数据说明见 [创意体验与联机服务](CREATIVE_FEATURES.md)。`piece-by-piece.zip` 包含源码、素材、测试、文档和构建，不含 node_modules 或用户照片；`SOURCE_CODE.md` 提供逐文件完整文本源码，二进制素材在压缩包 public 目录中。

## 新增的十项体验

1. **自动保存和续玩**：IndexedDB 保存最近一局的图片 Blob、原图、轮廓、切口、暂放位置、归位片、时间、次数、标记及难度。首页继续拼图可恢复；网页关闭期间不计时。
2. **照片构图**：上传后点调整构图，在大画布里拖动和缩放照片，结合实际完成轮廓预览。保留原图，重新调整时从原图处理，并恢复上次保存的缩放和位置。
3. **放大观察**：选片出现局部放大图，◉ 可进一步放大；画布支持 1–3 倍缩放、移图及全图。放大镜不会挡住落点。
4. **自由拼接**：允许先把纸片暂放在画布上；相邻切口对上后自动成组，拖任一片整组移动，接近目标一起吸附。收回可把选中组合送回盒中。未通关时已归位纸片也能重新选中、拖动或收回；可直接拖回纸片盒。取消按钮或 Esc 仅取消选择，保留位置。
5. **整理和辅助**：边缘/标记筛选、主要颜色排序、☆ 标记；底部「提示」高亮当前所选纸片的正确位置；••• 可帮忙放回一片。辅助次数公开计入成绩。
6. **每日与主题**：日期决定每日固定图片、片数、轮廓和切口；重来保留当日切口，记录本机最佳和连续完成天数。山水与花园、城市与房间、森林里的朋友各 3 关，9→25→49 片，完成前关才解锁后关，成绩弹窗可直接进入下一关，末关可探索其他主题。原有六关名画闯关保留。
7. **收藏墙**：完成后自动收录实际轮廓的作品，可看大图、原切口再拼、移入回收站及恢复；回收不清除通关历史。
8. **纪念卡**：成绩和收藏详情均可下载 1080×1420 PNG，含实际轮廓图片、日期、片数、时间、次数、分数和辅助次数，本地 Canvas 生成。
9. **氛围偏好**：右上角 ☷ 设置日间/深绿夜间、雨声/壁炉/海浪，以及音乐/环境声/机械音效独立音量；声音手动开启。粉碎动画可设每次/首次/关闭，仍可跳过或静音。
10. **防误触与引导**：••• 可撤销最近一次重切，恢复切口、暂放组合、进度和计时；首次游戏显示选片→放置→预览三步指引，可随时关闭和重看。

自由拼图支持 4–100 任意整数片数；圆形、爱心、星形、六边形、方形和手绘外轮廓。手绘点击后在大弹窗画布中绘制，支持自由描绘或点按描点。切口始终随机不规则，不使用固定行列网格。

## 新功能自测

- 拖动/缩放构图，保存后再次调整，应仍从原图处理。
- 暂放相邻片，出现切口对上反馈；拖动任一片整组移动，接近目标整组归位。
- 刷新后从首页续玩，比较切口、暂放位置、归位、次数和计时。
- 标记/边缘筛选与颜色排序；提示或帮放后辅助次数增长。
- 重切后撤销，恢复原几何、组合、时间和进度。
- 每日重新进入和重来均保留切口；主题首关完成后只解锁本主题第二关。
- 完成自动收藏，详情下载PNG、原切口再拼、回收和恢复。
- 切换日夜、三种环境声和三个音量；刷新保存偏好，但声音须手动启动。

- 分数=max(0,round(片数×250×困难系数−秒数×2−放置次数×8−辅助次数×350))；困难系数1.35，否则1。作为轻量本地记录，不是竞赛防作弊系统。
